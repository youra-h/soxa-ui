## Контракт прототипа

- В base новые общие настройки объявлены через `initial`: значение не задано и разрешён fallback.
  Буквально пустое значение CSS здесь не подходит, поскольку подавляет fallback.
- В oren заданы `--so-radius`, `--so-spacing` и пять независимых семейств множителей:
  `field`, `control`, `collection`, `message`, `surface`.
- Радиус компонента имеет приоритет над общим. Круглые элементы сохраняют форму.
  Большие панели и карточки сообщений сохраняют пропорцию 4/3 общего радиуса.
- Input и DateInput используют одинаковую шкалу `field`; Alert и Toasts используют `message`.
- Точная локальная длина имеет приоритет над расчётом и повторно не умножается.
- Отступы рассчитываются на компоненте, поэтому работают настройки на поддереве.
  Для телепортируемых слоёв важен их фактический DOM-контейнер.
- Шрифты, высоты контролов, минимальные зоны нажатия и отступы от окна сохраняют отдельные шкалы.
  Значения в em продолжают зависеть от шрифта.

| Размер | field/control | collection/message/surface | Зазор иконок Input после |
| ------ | ------------- | -------------------------- | ------------------------ |
| sm     | 0.75          | 0.875                      | 3 px                     |
| normal | 1             | 1                          | 4 px                     |

Раньше зазор иконок Input составлял 4 px при любом размере.

## Миграция, требующая решения владельца

Прежние переменные отступов, например `--so-input-indent-sm`, `--so-input-slot-spacing`
и `--so-button-padding-lg`, становятся необязательными точными переопределениями.
Установка прежней переменной в конкретную длину продолжает работать, включая `0px`.
Однако внешняя тема, напрямую читавшая её готовое значение по умолчанию, должна добавить
fallback или читать вычисленное CSS-свойство. Аналогично меняется значение по умолчанию
`--so-code-block-radius`.

Пример для самостоятельно оформляемого нормального поля:

```css
gap: var(
  --so-input-slot-spacing,
  calc(var(--so-spacing, 0.25rem) * var(--so-input-spacing-scale, var(--so-field-scale-normal, 1)))
);
```

Владелец отдельно одобрил эту миграцию перед подготовкой PR. Для обоих пакетов тем подготовлен minor-changeset с инструкцией обновления. Текущие версии вручную не меняются. Главная рабочая папка остаётся на main.

## Воспроизведение

Из корня рабочей ветки:

```powershell
npm run build:css --workspace=@soxa-ui/theme-oren
node tools/theme-geometry/capture.mjs before before-new-label
node tools/theme-geometry/capture.mjs after after-new-label
npm run test:theme
npm run test:browser --workspace=@soxa-ui/playground-vue
```

Инструмент отказывается перезаписывать существующую папку снимка. Для «до» он берёт
архивный CSS, а для «после» — текущую сборку. Рядом со снимками сохранены сами листы
CSS, их SHA-256 и измерения компонентов.

## Коррекция: отступы Toasts как основа для Alert

По решению владельца компактная геометрия исходного Toasts перенесена в Alert.
На normal вертикальные отступы Alert уменьшены с 16 до 14 px, горизонтальные остаются
16 px. Промежуток между заголовком и описанием уменьшен с 6 до 2 px. Значения других
размеров рассчитываются через общий множитель message. Размеры текста сохранены.

Сравнение измерений подтвердило одинаковые отступы Alert и Toasts во всех пяти размерах.
Локальный `--so-alert-padding` по-прежнему принимает полный CSS-shorthand, включая четыре
отдельных значения. Новый `--so-alert-body-gap` позволяет точно задать зазор текста.

После этой коррекции пройдены: 107 браузерных проверок Alert, Toasts и общей геометрии
(в том числе сравнение двух компонентов на каждом размере и проверка локальных
переопределений), 250 тестов тем, типы стенда и линтер. Итоговый полный браузерный набор после коррекции также пройден: 4608 проверок в 131 файле.

Исходные листы CSS сохранены в `theme.css.gz` без потери байтов. SHA-256 в `metrics.json` считается от распакованного CSS. Скрипт сравнения сам распаковывает архив; исходные незапакованные локальные копии также сохранены.
