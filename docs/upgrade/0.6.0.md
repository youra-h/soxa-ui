# Upgrading to 0.6.0

Upgrade the component packages and both supplied themes from `0.5.0` to `0.6.0`
together. Use `0.3.3` for either supplied icon pack you install. These icon
patches widen the peer range to admit the new component release.

## Who is affected

- Custom themes and application CSS that target modal backdrop classes need new selectors.
- Oren users can choose the modal backdrop appearance and set a default view for
  `Toasts`. Existing component usage continues to work.

## Before

Custom CSS selected the backdrop for each modal separately.

```css
.so-dialog__backdrop,
.so-alert-dialog__backdrop,
.so-drawer__backdrop {
  background: rgb(0 0 0 / 40%);
}
```

## After

Use the shared `.so-backdrop` class. If a rule applies to only one modal type,
match its adjacent panel with `:has(+ .so-dialog)`, `:has(+ .so-alert-dialog)`
or `:has(+ .so-drawer)`.

```css
.so-backdrop {
  background: rgb(0 0 0 / 40%);
}

.so-backdrop:has(+ :where(.so-drawer)) {
  background: rgb(0 0 0 / 25%);
}
```

`Dialog`, `AlertDialog` and `Drawer` accept a theme-defined `backdrop` prop.
Oren uses `dim` by default. Use `blur` for a tinted, blurred backdrop or `none`
for a transparent backdrop. Oren exposes `--so-backdrop-blur` to set the blur
radius. Its default is `3px`.

With Oren, set `view` to `outlined`, `filled` or `soft` on `Toasts` to select
the default for its notifications. Pass `view` in `show()` to override it for
one notification. See [Toast appearance in Oren](./toasts-soft-view.md) for a
complete example.

## Verification

1. Install the adapter and any directly installed `core`, `setup` and `plugins`
   packages at `0.6.0`. Check the lockfile and run the application's type check and
   production build.
2. Open each themed modal and verify its backdrop covers the viewport or the
   Drawer container. Check outside presses and focus with `dim`, `blur` and
   `none`, including any custom selectors.
3. Show notifications in both Oren schemes. Verify that an explicit item view
   overrides the manager and clearing it restores the manager's current view.
