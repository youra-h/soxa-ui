# Install Soxa UI 0.6.0 and Oren in Vue

In a Vue Vite app, install the packages for this sample with exact versions.

```sh
npm install --save-exact @soxa-ui/vue@0.6.0 @soxa-ui/setup@0.6.0 @soxa-ui/core@0.6.0 @soxa-ui/plugins@0.6.0 @soxa-ui/theme-base@0.6.0 @soxa-ui/theme-oren@0.6.0 @soxa-ui/icons-material@0.3.3
```

Use the `vue-main` example as `src/main.ts`. It registers Oren and Material
icons, then mounts the form and release examples. Save the example files from
`vue-bindings`, `vue-controller` and `vue-appearance` alongside `src/`.
