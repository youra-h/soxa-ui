# Soxa UI 0.6.0

Soxa UI provides headless components for Vue, React, Angular, Solid, Svelte and
Web Components. Keep core, setup, plugins and your adapter on the same library
version. Choose compatible theme and icon package versions independently.

This corpus covers the published 0.6.0 component API for all six adapters.
Use the record for your framework to find its exported components, props,
events, models and slots. The generated types describe the headless library.
A theme can augment them with values such as backdrop and notification views.

Read `release-changes` before upgrading from 0.5.0. For a Vue and Oren sample,
start with `vue-start`.
