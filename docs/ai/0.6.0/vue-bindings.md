# Vue models and events

Use `v-model:value` for Input, CheckBox, Select and DatePicker. Use
`@change:value` for the Input's change payload; its `newValue` is the
new field value. A visible label associates the input with its accessible name;
the Select and DatePicker example uses their explicit `aria_label` prop.

Save the `recipes` example as `TravelRecipes.vue` at the project root.
