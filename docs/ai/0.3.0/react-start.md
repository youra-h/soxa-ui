# React and Next.js consumer entry point

These records target published Soxa UI **0.3.0**. Load react-installation first,
then react-bindings, react-composition and the component's api-react-* record.
For programmatic state use react-controller; for the App Router load react-next.
Read react-errors when types, registration or hydration fail.

The related API records are generated from the verified published setup artifact.
Use their actual React import, props, event callback bindings and slot scopes.
Do not infer React bindings from Vue syntax or the current library checkout.
The shared overview owns the headless model, theming and accessibility overview.

Checked scope: a typed travel form (Input, CheckBox, Select, DatePicker),
Accordion scoped content, Button controller lifetime, and Next.js server references
with Tabs parts. This is sample framework coverage, not all component recipes.
The attached source is shared between Vite and Next; it is not a component library fork.
