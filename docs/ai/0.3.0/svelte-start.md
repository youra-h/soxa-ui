Load this entry and only the record needed for your task. Use svelte-installation
for the runnable project, svelte-bindings for controlled state, svelte-composition
for compound components/snippets, svelte-controller for imperative ownership,
svelte-sveltekit for universal rendering, and svelte-errors for release limits.
Use related api-svelte-* records for actual props, payloads and slot scopes.

This is narrow consumer coverage, not adapter implementation guidance. All Soxa
packages here are exactly 0.3.0; current main/latest are not API references.

The examples are runtime recipes, not a claim of a fully passing typed consumer.
