# Vue and Nuxt 0.3.0 entry point

Start with vue-installation, then select vue-bindings, vue-composition,
vue-controller, vue-nuxt and vue-errors as needed. Retrieve the related
generated api-vue-* records for exact imports, props, events and slot scopes.
The checked scope is the attached travel form, Select/DatePicker, Accordion
and controller lifecycle. Other components need their own checks.
Use only the selected 0.3.0 corpus. Its generated base theme types are
unaugmented; the installed Oren setup adds Oren's values.
