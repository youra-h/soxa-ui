# Web Components 0.4.1

Start here, then retrieve webc-installation, webc-bindings, webc-composition,
webc-lifecycle, webc-environment, webc-errors or webc-validation as needed.
Read overview for the shared version, theme augmentation and audience boundary.
Read the related api-webc-* records for exact public properties, events and slots.
This is application usage of published 0.4.1, not instructions for changing Soxa.

Coverage is sample: a typed Vite travel form, Select + DatePicker, Accordion,
light-DOM content, native form values, cancelable events and removal of open layers.
Do not mix newer package APIs or another adapter's syntax into this corpus.
Web Components execute in the browser. Server-authored HTML can be upgraded there;
this is not the SSR/hydration contract of the framework adapters.
